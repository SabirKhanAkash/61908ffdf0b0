# Project DVM

This workspace contains the source code for the Device Vital Monitor (DVM) system, divided into a Flutter frontend and a Node.js backend.

## 📱 Frontend (dvm_app)
- [**README**](./dvm_app/README.md): Setup and running instructions for the Flutter application.
- [**AI Log**](./dvm_app/ai_log.md): Log of AI collaboration and prompts used during development.
- [**Decisions**](./dvm_app/DECISIONS.md): Documentation of key architectural and design ambiguities.

## 🖥️ Backend (dvm-backend)
- [**README**](./dvm-backend/README.md): Setup and running instructions for the Node.js/Express backend.
- [**AI Log**](./dvm-backend/ai_log.md): Log of AI collaboration and prompts for the backend.
- [**Decisions**](./dvm-backend/DECISIONS.md): Documentation of backend ambiguities and design choices.
